# Portfolio Frontend

A modern, responsive portfolio website built with React, Vite, and styled with a clean beige/white theme.

## Tech Stack

- **Frontend**: React 19, Vite
- **Routing**: React Router DOM
- **State Management**: TanStack React Query
- **HTTP Client**: Axios
- **Styling**: CSS Modules with custom design system

## Prerequisites

- Node.js (v16 or higher)
- npm or yarn
- Backend API running (see Backend section)

## Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/SwaroopAV21/portfolio-frontend.git
   cd portfolio-frontend
   npm run dev
   ```
